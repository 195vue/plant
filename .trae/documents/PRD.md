# 乌江渡水电站数字孪生管理平台 PRD

## 1. 产品概述

乌江渡水电站数字孪生管理平台是一个集三维可视化展示与后台数据管理于一体的综合管理平台。系统由大屏看板和后台管理系统两部分组成，共用统一用户认证体系。大屏看板通过 UE5 像素流推送技术展示全厂三维数字孪生场景，后台管理系统负责图纸、设备、管道、资料等数据的维护，为大屏看板提供数据底座支撑。

- **目标用户**：水电站运行管理人员、检修人员、管理人员及浏览访客
- **核心价值**：通过数字孪生技术实现水电站设备管网的可视化管理，提升运维效率与决策能力

## 2. 核心功能

### 2.1 用户角色

| 角色名称 | 大屏看板权限 | 后台入口 | 后台操作权限 |
|----------|-------------|----------|-------------|
| 管理员 | 全部功能（含漫游路线管理） | 可见 | 全部模块全部权限 |
| 操作人员 | 全部功能（含漫游路线管理） | 可见 | 图纸管理、设备数字化、管道数字化、资料管理 |
| 浏览人员 | 只读（可定位设备、使用默认漫游、查看告警） | 不可见 | — |

### 2.2 功能模块

1. **登录页面**：用户身份认证入口，登录后默认进入大屏看板
2. **大屏看板**：三维可视化展示，含结构树导航、属性信息、3D 场景、漫游管理
3. **后台管理系统**：
   - 工作台：系统概览与待办事项
   - 图纸管理：图纸上传、审批、版本管理
   - 设备数字化：设备管理、属性资料、编码管理、BIM 驾驶舱
   - 管道数字化：管路结构树、管路分类管理、属性管理、阀门管理
   - 资料管理：资料上传、挂接、预览、下载
   - 系统配置：组织机构、角色管理、用户管理、数据字典、工作流管理、日志查询

## 3. 核心流程

### 3.1 用户登录流程

用户在登录页输入用户名、密码、验证码 → 系统验证身份 → 根据角色跳转：管理员/操作人员→大屏看板（显示后台入口）；浏览人员→大屏看板（无后台入口）。

```mermaid
flowchart TD
    "用户访问系统" --> "登录页面"
    "登录页面" --> "输入用户名密码验证码"
    "输入用户名密码验证码" --> "验证身份"
    "验证身份" -->|失败| "显示错误信息"
    "验证身份" -->|成功| "判断角色"
    "判断角色" -->|管理员/操作人员| "大屏看板(含后台入口)"
    "判断角色" -->|浏览人员| "大屏看板(无后台入口)"
```

### 3.2 大屏交互流程

结构树点击节点 → 节点高亮 → 右侧面板加载属性 → WebSocket 通知 3D 引擎 → 3D 场景飞行定位 → 模型高亮显示。

```mermaid
flowchart LR
    "结构树节点点击" --> "节点高亮"
    "节点高亮" --> "右侧面板加载属性"
    "右侧面板加载属性" --> "WebSocket 发送定位指令"
    "WebSocket 发送定位指令" --> "3D 场景飞行定位"
    "3D 场景飞行定位" --> "模型高亮显示"
```

### 3.3 图纸审批流程

上传图纸 → 状态"待审批" → 管理员审核 → 通过（状态"已通过"）/驳回（状态"已驳回"，记录原因）。

```mermaid
flowchart LR
    "上传图纸" --> "状态: 待审批"
    "状态: 待审批" --> "管理员审核"
    "管理员审核" -->|通过| "状态: 已通过"
    "管理员审核" -->|驳回| "填写驳回原因"
    "填写驳回原因" --> "状态: 已驳回"
```

## 4. 用户界面设计

### 4.1 设计风格

- **主色调**：深色科技风（#1a1a2e 深蓝黑）用于大屏看板；浅色商务风用于后台管理
- **强调色**：科技蓝（#1890ff）用于交互元素、选中态、主按钮
- **辅助色**：绿色（成功/已通过）、橙色（警告/待处理）、红色（危险/告警/已驳回）
- **字体**：思源黑体（中文）+ Roboto（数字/英文），数据展示使用等宽数字字体
- **布局风格**：大屏看板采用深色全屏沉浸式布局；后台采用经典左导航+顶栏+内容区
- **图标风格**：线性图标（如 Ant Design Icons），3D 场景使用 HUD 风格叠加

### 4.3 响应式

- 桌面优先设计，最小支持 1366×768 分辨率
- 大屏看板针对 1920×1080 及以上分辨率优化
- 后台管理系统在 1280px 以上正常显示，低于此宽度表格横向滚动
- 不做移动端适配（工业管理系统场景）

### 4.4 3D 场景说明

- 由于原型阶段无真实 UE5 像素流，3D 场景区域使用占位图/模拟画面展示
- 模拟画面显示水电站三维场景的静态截图或加载动画
- HUD 信息、漫游工具条等叠加元素正常实现交互
- WebSocket 通信逻辑用 Mock 数据模拟

## 5. 技术约束

- 前端框架：React 18 + Vite
- UI 组件库：Ant Design 5.x
- 路由：React Router 6
- 状态管理：Context API + useState（原型规模）
- 样式：Tailwind CSS + CSS Modules
- 图表：ECharts
- 数据：全部 Mock 数据，无后端
- 浏览器：Chrome/Edge 最新版
